Esse é um projeto que foi desenvolvido para concluir uma prova da disciplina de Desenvolvimento de Sistemas Web

Segue abaixo o passo à passo para rodar o projeto:

1 - baixar e ativar o ambiente virtual
 
python -m venv venv 
Venv/Script/Activate

2 - Baixe as dependências ( o arquivo requirements pode estar com problemas, mas só foi utilizado o django )

pip install django

3- rodar o projeto 

python manage.py runserver
